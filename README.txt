對話實驗室 — GitHub Pages version

1. Extract the ZIP.
2. Put these six images inside assets/ (images are not included):
friend-conflict.jpg
friend-conflict-choices.jpg
relationship-boundaries.jpg
relationship-boundaries-choices.jpg
homework.jpg
homework-choices.jpg
3. Upload index.html, style.css, app.js and assets/ to your repository root.
4. Keep GitHub Pages set to main / (root).

Story images must be a 2 x 2 grid. Choice images are divided into three full-height columns, preserving 100% of the image. Adjust PANELS and CARDS at the top of app.js if needed.
The original images are not animated internally; entrance/selection transitions animate the interface.
Progress is saved in this browser only. No accounts, server, or student data collection is included.
Feedback is a possible outcome, not a guaranteed consequence. Original comic endings are labelled as demonstrations, not branching artwork.
